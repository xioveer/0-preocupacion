# La Granja de Fresitas

Un juego web tierno, de un solo archivo (`index.html`), hecho con mucho amor para animar el día.

## Cómo jugarlo

Abre `index.html` en el navegador del celular o del computador. No necesita instalar nada.
Si lo publicas con GitHub Pages (Settings, Pages, rama `main`), queda disponible con un enlace para compartir.

## Qué tiene

- **Huerto:** planta fresas, rosas rojas y lirios, riégalos, espera a que crezcan y cosecha.
- **Taller:** prensa las fresas más grandes y rojas para hacer Vino Tinto de Fresa, y arma ramos de rosas y lirios.
- **Mercado:** vende y gana Fresipuntos para desbloquear luces, lazos, una camita, macetas y un arco de rosas.
- **Lluvia de Fresas:** minijuego para atrapar fresas con la cesta (dedo, mouse o flechas), con 3 vidas.
- **Rincón del Descanso:** té de manzanilla, cobijita y mensajes de cariño.
- Música lo-fi y efectos de sonido generados por código (Web Audio API), con botones para activarlos o apagarlos.

El progreso se guarda solo en el navegador.

## Personalizar

Los mensajes de amor están en el objeto `MSG` dentro de `index.html`; se pueden cambiar o ampliar con frases propias.
